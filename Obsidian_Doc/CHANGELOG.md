## 🔄 Processo de Atualização

### Quando Atualizar

- **Semanal:** Se houver alterações significativas no código
- **Mensal:** Revisão completa de consistência
- **Por Milestone:** Atualização de roadmap e status
- **Por Request:** Se solicitado por stakeholders

### Como Atualizar

1. **Identifique a alteração**
2. **Determine a categoria**
3. **Atualize o documento relevante**
4. **Adicione entrada ao changelog**
5. **Revise wikilinks quebrados**
6. **Teste navegação**
7. **Commit para versionamento**

### Template de Entrada

```markdown
## [Versão] - Data

### Adicionado
- [ ] Descrição da adição
- [[Link para documento]]

### Alterado
- [ ] Descrição da alteração
- [[Link para documento]]

### Corrigido
- [ ] Descrição da correção
- [[Link para documento]]
```
